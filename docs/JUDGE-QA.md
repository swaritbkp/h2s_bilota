### Q4: Why not just use ChatGPT or a generic LLM wrapper?
**Answer**:  
Generic LLMs lack contextual Indian labor law grounding, hallucinate rupee math, fail to extract complex code-switched Hinglish/Kannada audio notes, and cannot interactively triage emergency safety protocols. Saathi is a purpose-built domain pipeline that combines Layer 1 prompt injection defense, statutory mapping to the Code on Social Security 2020, and rapid 108 emergency telephony integration into an end-to-end worker advocacy workflow.

### Q5: How does this system scale to handle 100x traffic during a city-wide strike or storm?
**Answer**:  
Our backend is built on a stateless FastAPI application containerized via Docker and deployed on Google Cloud Run, which auto-scales horizontally from 0 to hundreds of container instances instantly. Furthermore, repeat queries and standard dispute notices leverage our high-efficiency LRU cache, servicing identical requests in under 5 ms without consuming any LLM quota.

### Q6: How do you handle governance, prompt versioning, and worker privacy?
**Answer**:  
Every transaction is scrubbed of PII (Aadhaar, mobile, vehicle plates) by our Layer 1 shield before processing, and logged to an append-only audit trail in [`logs/audit.jsonl`](file:///c:/Users/S/OneDrive/Desktop/WarmupSesson/logs/audit.jsonl). We enforce semantic versioning (`PROMPT_VERSION = "v1.0"`, `AGENT_VERSION = "1.0.0"`) across all telemetry payloads, and flag any prediction with grounding confidence under 0.75 for human review.  
- **Repo Evidence**: [`src/core/guardrails.py:sanitize_input_l1`](file:///c:/Users/S/OneDrive/Desktop/WarmupSesson/src/core/guardrails.py#L25-L65), [`logs/audit.jsonl`](file:///c:/Users/S/OneDrive/Desktop/WarmupSesson/logs/audit.jsonl).
